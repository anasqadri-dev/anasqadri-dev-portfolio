# Muhammad Anas Qadri — Portfolio

My personal portfolio website — built to showcase my work as a Software Engineer focused on backend engineering with Java and Spring Boot, along with full-stack development, projects, and open-source work.

**Live:** [anasqadri-dev.me](https://anasqadri-dev.me)

## About

A minimal, dark-themed, technical portfolio site covering my background, technology ecosystem, featured projects, open-source activity, blog writing, and experience/education. Built as a genuine production site — not a template — with centralized content data, full SEO metadata, structured data, and live GitHub stats.

## Tech Stack

- **Framework:** Next.js 16 (App Router, Server Components)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** GSAP (ScrollTrigger)
- **3D:** Three.js via `@react-three/fiber`
- **Icons:** Lucide React, Simple Icons
- **Fonts:** Space Grotesk, Inter, JetBrains Mono

## Features

- Hero section with a lightweight, interactive Three.js node-network visual
- Technology ecosystem organized by category (Backend, Frontend, Databases, Data & Messaging, DevOps & Cloud, Tools)
- Featured Projects grid (MailMate, Streamly, Wavelength, Zikr-ul-Quran, Heritage Blog, File Organizer CLI)
- Open Source section with **live stats pulled directly from the GitHub API**
- Blog section linking to Hashnode, Dev.to, and Medium
- Education & teaching experience timeline
- Full SEO: metadata, Open Graph, Twitter Cards, JSON-LD structured data, sitemap, robots.txt
- Fully responsive, accessible (semantic HTML, focus states, reduced-motion support)
